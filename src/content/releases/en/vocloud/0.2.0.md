### Added
- DNS-based host discovery alongside the static inventory.
- Certificate issuance for hosts tagged `tls`.

### Changed
- A runner holds one multiplexed connection per host for the whole job
  ([decision 3](/projects/vocloud/decisions/#d003)). WAN apply went from 71 s
  to 38 s.
- `concurrency` is validated against the process descriptor limit at start-up
  instead of failing mid-run.

### Fixed
- `plan` no longer reports drift for units whose only difference was key order
  in the generated file.
